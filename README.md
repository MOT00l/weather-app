## 💡 About

Clima Weather is a modern weather application built to explore advanced Flutter UI development while focusing on clean architecture, responsive design, smooth animations, and efficient state management.

Rather than creating a simple weather app, the goal was to deliver an experience that feels polished and intuitive through elegant animations, glassmorphism, and thoughtful user interactions.

---

## ✨ Features

- 🌍 Search weather by city
- 📍 Current weather conditions
- 📅 Multi-day weather forecast
- 🌡️ Detailed weather information
    - Temperature
    - Feels Like
    - Humidity
    - Wind Speed
- 🎨 Material 3 design
- 🪟 Glassmorphism interface
- 🌈 Animated gradient background
- ☁️ Floating animated blobs
- ⚡ Smooth page transitions & animations
- 💾 Local weather caching
- 🕒 Last updated indicator
- 📱 Responsive layout

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/MOT00l/weather-app.git
```

### Navigate into the project

```bash
cd weather-app
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
